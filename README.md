# Old Baby Animals

Client-side Fabric mod for Minecraft 26.3 that restores the pre-Tiny Takeover (pre-26.1)
baby mob look: the adult model at half size with adult textures, and the old sounds.
Hitboxes stay the new ones, so it works on any server.

**Status:** early draft. Mixins are unverified against 26.3 and textures/sounds are not done yet.

## Build
Requires Java 25.

    ./gradlew build

The jar is in `build/libs/`. Fill in the version TODOs in `gradle.properties` first
(see https://fabricmc.net/develop).
